SpotHail SpotHail is a real-time, WebSocket-powered radar platform designed entirely for the unorganized shared auto and e-rickshaw sector.Over 60 million daily commuters in India rely on informal shared transit, yet this massive fleet remains digitally invisible. SpotHail solves the "blind curb wait" by providing commuters with live map visibility and real-time seat tracking, while empowering drivers with a zero-typing, low-bandwidth digital HUD. We operate on a zero-ride-commission, zero-OTP model, providing digital dignity and professional parity to the informal transit workforce.  Key Features For Drivers (The Supply Side)Zero-Typing HUD: Designed for chaotic driving environments. Features massive, tactile [+] and [-] seat capacity buttons.Acoustic Feedback: Integrated Web Audio API chimes confirm updates without requiring the driver to look at the screen.Ultra-Low Bandwidth: Sends lightweight 100–200 byte telemetry packets, ensuring high reliability on spotty 4G networks (~₹10/month data cost).Background GPS Wake-Lock: Maintains consistent location polling even when the screen is locked or the app is minimized.Automated Stale-Auto Purge: Vehicles are automatically removed from the active map if no movement or update is detected for 90 seconds, preventing "ghost seats."🧍‍♂️ For Commuters (The Demand Side)Real-Time Corridor Radar: View exactly where shared autos are on specific 3–5 km transit routes.Live Seat Capacity: Know exactly how many seats are empty before the auto even pulls up to the curb.Frictionless Experience: No ride booking, no OTPs, and no surge pricing. Just see it, hail it, and board it.🏗️ System Architecture & Tech StackSpotHail is engineered to be a lightweight, highly concurrent, and hardware-efficient platform to prevent cloud vendor lock-in and keep fixed OpEx strictly capped.Frontend (Commuter & Driver UI): Next.js (React), optimized for fast mobile-web rendering.Real-Time Telemetry: Node.js with Socket.io handling high-frequency, bidirectional WebSocket connections for sub-200ms state updates.Mapping Engine: Leaflet utilizing completely free and open-source OpenStreetMap (OSM) tiles for performant, cost-free geospatial rendering.Infrastructure (Phase 1): Containerized via Docker and deployed on cost-efficient cloud providers (DigitalOcean/Render) to maintain the ₹900/month server ceiling.Payment Automation: Razorpay/Cashfree Webhooks for zero-touch Pro subscription unlocking (Day 61 hard paywall).🚀 Local Development SetupFollow these steps to run SpotHail locally for development and testing.PrerequisitesNode.js (v18.x or higher)npm or yarnInstallationClone the repositorygit clone https://github.com/UtkarshSgr/SpotHail.git
